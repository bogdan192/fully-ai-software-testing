# FaST press kit

## Project

**FaST — Fully AI Software Testing**

**Concept and Paradigm, created by Bogdan Stefan Plesa.**

FaST is a proposal for agent-led software-testing workflows. Its public reference separates the agent that chooses actions from the execution boundary and the checks that evaluate observed application behavior.

## Short author bio

Bogdan Stefan Plesa is the creator of the FaST concept and paradigm documented in the Fully AI Software Testing project. He explores autonomous testing workflows, application evidence, and the evaluation of testing agents. His public profiles are [LinkedIn](https://www.linkedin.com/in/bogdanplesa/) and [GitHub](https://github.com/bogdan192).

## What readers can try

The MIT-licensed Python demonstration runs without external dependencies in offline mode. It exercises a synthetic user's creation, login, order, refund, and disabling, then checks whether access remains possible. Two injected faults demonstrate duplicate refunds and stale sessions. The optional LangChain adapter chooses actions using a configured model; optional LangSmith tracing exposes model calls.

The reference is an architectural demonstration, not a deployed customer product. Ten offline tests and automated CI validate the harness. No live-model reliability, commercial adoption, or productivity improvement is claimed.

## Story angles

- **Who checks an AI tester's work?** A practical explanation of independent evidence and inconclusive outcomes.
- **From test scripts to testing objectives.** The FaST proposal and the distinction between script generation and adaptive investigation.
- **A disabled user still has access.** A reproducible example showing why observation order can hide a session defect.
