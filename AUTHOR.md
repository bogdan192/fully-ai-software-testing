## The FaST contribution

FaST describes an agent-led operational testing loop with explicit boundaries. A person defines the objective and permitted environment. An agent chooses and performs experiments. Separate checks examine application evidence. A report distinguishes observed failures, supported successes, and missing evidence.

The initial architectural reference demonstrates this separation using account creation, login, orders, refunds, and user disabling. Its offline mode is deterministic; an optional LangChain adapter provides model-driven action selection. LangSmith tracing is available by explicit opt-in.
