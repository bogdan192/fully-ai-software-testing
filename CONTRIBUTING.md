# Contributing

FaST concept and paradigm: Bogdan Stefan Plesa.

Start with a reproducible observation. Include the command, Python version, planner mode, model identifier if used, and sanitized evidence. Do not include API keys, personal data, session cookies, or real payment records.

Run `python -m unittest discover -s tests -v` before proposing code changes. Changes to the evaluator need a regression case showing the behavior they distinguish. Keep the default demo runnable offline. Document whether a new component is implemented, experimental, or only proposed.

For claims about performance or novelty, link the underlying evidence and describe the comparison. Preserve attribution to relevant prior work. Contributions are offered under this repository's MIT license.
